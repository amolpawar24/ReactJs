# ⚛️ React App Using NPM Global

This project demonstrates the traditional method of creating a React application by **globally installing Create React App using npm**.

> ⚠️ **Note:** Create React App (CRA) is a legacy approach and is not recommended for new React projects. This repository is maintained for learning and research purposes.

---

## 🚀 Create React App

### 1. Install Create React App Globally

```bash
npm install -g create-react-app
```

### 2. Create React Application

```bash
create-react-app React-NPM
```

### 3. Navigate to Project

```bash
cd React-NPM
```

### 4. Start Development Server

```bash
npm start
```

The application will run on the local development server.
