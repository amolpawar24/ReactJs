# ⚛️ React App Using Vite + NPX

This project demonstrates how to create a **React application using Vite with NPX**.

## 🚀 Create React App

### 1. Create the Project

```bash
npx create-vite@latest React-Vite-NPX
```

### 2. Select React

```text
Select a framework: React
Select a variant: JavaScript
```

Or create it directly with JavaScript:

```bash
npx create-vite@latest React-Vite-NPX --template react
```

### 3. Navigate to Project

```bash
cd React-Vite-NPX
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Start Development Server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.

## 📂 Basic Structure

```text
React-Vite-NPX/

│   ├── App.jsx
│   ├── main.jsx
│   └── index.css

```

## 🛠️ Technologies

## 📌 Note

`npx create-vite` is used to **scaffold the Vite project**. After creation, `npm install` installs the project dependencies and `npm run dev` starts the development server.
