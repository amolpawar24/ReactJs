# ⚛️ React App Using NPX

This repository demonstrates how to create a **React application using NPX and Create React App (CRA)**.

## 🚀 Create React Application

### 1. Create the React App

```bash
npx create-react-app React-NPX
```

### 2. Move into the Project

```bash
cd React-NPX
```

### 3. Start the Application

```bash
npm start
```

The React application will start on the local development server.

---

## 🔄 Complete Command

npx create-react-app React-NPX
